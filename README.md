# Sr

Grabador de pantalla y capturas para Android (Kotlin, sin dependencias externas).

- Video H.264 / H.265, 480p / 720p / 1080p, 30 / 60 fps, bitrate variable (VBR)
- Audio interno (Android 10+), capturas PNG, galería y reproductor integrados
- Guarda en `Movies/Sr` y `Pictures/Sr`
- APK firmado en la sección Releases (se compila con GitHub Actions)
